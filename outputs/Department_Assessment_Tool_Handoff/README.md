# Department Assessment Tool — Handoff Package

This folder lets you create a new assessment tool for any company department by using Codex.

## Start here

1. Copy this entire folder to your computer.
2. Open the folder as a workspace in Codex.
3. Complete `DEPARTMENT_INFORMATION.md`.
4. Open `START_PROMPT_FOR_CODEX.txt`.
5. Replace `[DEPARTMENT NAME]` with the real department name.
6. Copy the full prompt and send it to Codex.
7. Review and approve the proposed domains and questions before allowing Codex to edit the application.

## Folder contents

- `working/Department_Assessment_Tool_EDITABLE.html` — the file Codex may edit.
- `reference/Cost_Control_Assessment_Tool_REFERENCE_ONLY.html` — the original example; never edit it.
- `assets/madkour-logo.png` — company branding asset.
- `DEPARTMENT_INFORMATION.md` — information to complete before starting.
- `START_PROMPT_FOR_CODEX.txt` — ready-to-send starting prompt.
- `INSTRUCTIONS_FOR_CODEX.md` — detailed rules Codex must follow.
- `TESTING_CHECKLIST.md` — final acceptance checklist.
- `Department_Question_Template.xlsx` — editable register for reviewing domains and questions.

## Important

- Keep the `reference` file unchanged.
- Do not place confidential employee data, passwords, or restricted documents in this folder.
- Department management must approve the assessment content.
- Make a backup before major changes.
