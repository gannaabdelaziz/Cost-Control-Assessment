# Instructions for Codex

## Objective

Create a separate assessment tool for the department named in `DEPARTMENT_INFORMATION.md`, using the Cost Control application as the functional and visual reference.

## File rules

1. Edit only `working/Department_Assessment_Tool_EDITABLE.html`.
2. Never modify `reference/Cost_Control_Assessment_Tool_REFERENCE_ONLY.html`.
3. Preserve `assets/madkour-logo.png`.
4. Keep all work inside this project folder.
5. Make changes in stages and verify the application after each material stage.

## Approval gates

Do not edit the HTML immediately.

First:

1. Read all instruction files.
2. Review the reference application.
3. Review `DEPARTMENT_INFORMATION.md`.
4. Identify missing information and clearly state any assumptions.
5. Propose assessment domains, categories, weights, and question count.
6. Wait for the user's approval.
7. Draft the full question register with evidence and recommended actions.
8. Wait for the user's approval again.
9. Only then update the editable HTML.

## What must be customized

- Application title and department name
- Introductory and explanatory text
- Domains and domain weights
- Categories and question weights
- Assessment questions
- Evidence requested
- Process references
- Business impacts
- Suggested owners and stakeholders
- Improvement actions and roadmap wording
- KPIs and management-report wording
- Exported filenames and backup storage key, so it does not overwrite the Cost Control tool's browser data

## What must be preserved

- Madkour branding and general visual design
- Dashboard
- Assessment workflow
- Maturity scoring from 1 to 5
- Gap and severity analysis
- Heatmaps and charts
- Roadmap generation
- Executive brief and operational report
- CSV/JSON export and JSON import
- Save, history, reset, and backup functions
- Print/PDF behavior
- Responsive layout and navigation

## Assessment quality rules

- Assess the department and its processes, not individual employee performance.
- Use clear, evidence-based questions.
- Do not invent company policies, system names, or organizational facts.
- Mark assumptions and request confirmation.
- Avoid duplicate or combined questions.
- Domain weights must total 100%.
- Question weights within each domain must be consistent with the application's scoring method.
- Use department specialists to approve the final content.

## Required verification

Before completion:

- Search for and remove inappropriate Cost Control-specific wording.
- Confirm department and question weights calculate correctly.
- Test saving and reopening.
- Test JSON export/import and CSV export.
- Test reset behavior.
- Test dashboard, gaps, roadmap, and reports.
- Test the executive brief and print/PDF view.
- Confirm the editable app uses a new local-storage key.
- Confirm the reference file is unchanged.
- Report all changed files and any remaining assumptions.
