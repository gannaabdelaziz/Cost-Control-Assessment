# Final Testing Checklist

## Content

- [ ] The correct department name appears throughout the application.
- [ ] No inappropriate Cost Control-specific wording remains.
- [ ] All approved domains, categories, and questions are present.
- [ ] Evidence, owners, actions, KPIs, and report language fit the new department.
- [ ] Assumptions are documented and approved.

## Scoring

- [ ] Domain weights total 100%.
- [ ] Question weights follow the approved framework.
- [ ] Maturity levels 1–5 work correctly.
- [ ] Overall score, gaps, priorities, and severity calculations are correct.
- [ ] Completion percentage is correct.

## Features

- [ ] Dashboard loads correctly.
- [ ] Assessment answers can be entered and edited.
- [ ] Gaps and heatmaps update correctly.
- [ ] Roadmap actions are generated correctly.
- [ ] Executive brief and operational report use the new department content.
- [ ] CSV export works.
- [ ] JSON backup export and import work.
- [ ] Save/history works.
- [ ] Reset works only after confirmation.
- [ ] Print/PDF layout is readable.

## Data separation and safety

- [ ] The new tool uses a unique browser local-storage key.
- [ ] It does not overwrite Cost Control assessment data.
- [ ] The reference HTML remains unchanged.
- [ ] No confidential answers or personal data are included in the shared folder.

## Browser check

- [ ] Tested in Microsoft Edge or Google Chrome.
- [ ] No visible errors, broken buttons, or missing sections.
- [ ] The application still works after closing and reopening the browser.
